# ClawMachineClaude

ブラウザで遊べるクレーンゲームです。ビルドやインストールは不要で、`index.html` をブラウザで直接開くと遊べます。

## 遊び方

- ← → キー：アームを左右に動かす
- スペースキー：アームを下ろす（つかんだら自動で取り出し口まで運ぶ）
- R キー：景品を並べ直して最初から
- M キー：効果音のオン・オフ

画面の下のボタン（← 下ろす →）でも操作できるので、スマホでも遊べます。

景品は くま・ねこ・ひよこ・うさぎ・ペンギン・おばけ の 6 種類です。景品の真ん中を狙うほどつかみやすく、途中で落としにくくなります。

## フォルダ構成

```
index.html      画面の土台。js/ のファイルをこの順番で読み込む
css/style.css   ページの見た目
js/config.js    画面サイズや色などの設定値
js/sprites.js   景品とアームのドット絵（1 文字が 1 ドット）
js/input.js     キーボードと画面のボタンの入力の管理
js/prize.js     景品の配置と物理（重力・床・壁・景品どうしの衝突）
js/claw.js      アームの動きと、景品をつかむ判定
js/effects.js   獲得したときの紙吹雪と文字の演出
js/sound.js     効果音（Web Audio で音を作るので、音声ファイルは不要）
js/render.js    筐体・電飾・景品・アーム・獲得数の描画
js/main.js      起動処理とメインループ
```

ES モジュールは使わず、`index.html` の `<script>` の順番で読み込んでいます。ファイルを直接開いたときもそのまま動かすためです。
