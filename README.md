# ClawMachineClaude

ブラウザで遊べるクレーンゲームです。ビルドやインストールは不要で、`index.html` をブラウザで直接開くと遊べます。

## 遊び方

最初のメニュー画面は、上から「モードのタブ（フリー・チャレンジ・ステップ）」「難しさ（かんたん・ふつう・むずかしい）」「ジャンルごとのゲームのボタン」の順に並んでいます。ゲームのボタンを押すと、1 回で始まります。モードを切り替えても、タブや難しさのボタンの位置は変わりません（一番項目の多いフリーの高さにそろえています）。ゲームのボタンが画面に収まらないときは、ゲームのボタンの部分だけを上下にスクロールできます（タブと難しさのボタンはいつも上に出ています）。

ゲームは、ボタンを 1 回押すだけで遊べる「ワンタッチ」（おまかせ・ショベル・おまかせバンバン）、アームを動かしてつかむ「アームで つかむ」（クラシック・2ボタン・3本爪・2ボタン ガイド・3本爪 ガイド）、しかけを使って落とす「しかけで おとす」（リング・リング2だん・バンバン・スウィート）、「おたのしみ」（ランダム）に分けて並べています。ゲームのボタンは `js/config.js` の `GAMES`（名前・説明・ジャンル・むずかしさの目安・ステップでクリアに必要な景品の数）と `GENRES`（見出し）から `js/menu.js` が作るので、ゲームを増やすときはここに足します。キーボードでは Tab でモード、← → で難しさ、↑ ↓ でゲームを選んで Enter（ボタンの左の数字キーでも始まる）です。スマホなど幅のせまい画面では、説明文と数字を省きます。選んだモードと難しさは、次に開いたときも残ります。

- **フリー**：全部のゲームを、コインいらずで自由に遊べます（1 ゲーム 10 回）。取った景品は図鑑に入ります。
- **チャレンジ**：1 回下ろすごとに銀コインを 1 枚使います。銀コインがあるだけ、どのゲームでも続けて遊べます。景品を取ると、景品のほかに金コインがもらえます。枚数は「景品の点数 ÷ 30（四捨五入、1 枚以上）× ゲームの ★ の数 × 難しさの倍率（かんたん 1・ふつう 2・むずかしい 3）」です。メニューのボタンに、1 こでもらえる枚数の幅が出ます。ランダムはありません。
- **ステップ**：1 ゲーム（10 回）遊ぶのに金コインを 3 枚使います。ゲームはジャンルごとの段に分かれていて、「1だんめ：ワンタッチ」→「2だんめ：アームで つかむ」→「3だんめ：しかけで おとす」→「4だんめ：さいごの だい」の順に進みます。最初は 1 だんめのゲームが全部遊べ、段の中のどれか 1 つで、ゲームごとに決めた数の景品を取るとクリアになって、次の段のゲームが全部遊べるようになります（苦手な台で止まらないように、好きな台で進めるようにしています）。クリアした段のほかの台も、続けて遊べます。段の分け方は `js/config.js` の `STEP_STAGES` にあり、どの段に入るかは `GAMES` の `genre` で決まります。どこまで進んだかは難しさごとに別々に記録します（かんたんでクリアしても、ひらくのはかんたんだけ）。
  - 3 だんめまでクリアすると、4 だんめの最後の台「**ぬしの台**」が遊べるようになります（金コイン 10 枚）。大きな「ぬし」は大きすぎてつかめないので、アームを当てて体力（100）を減らします。真ん中に当てるほど大きく減り、当てると取り出し口の方へ少し押し戻せます。体力を 0 にすると取り出し口へ転がり落ちてゲットです。難しさごとに ぬし が違い（かんたん：たこ、ふつう：くじら、むずかしい：ドラゴン）、ふつうとむずかしいでは ぬし が左右に動きます。設定は `CONFIG.boss` にあります。
  - ぬし は図鑑の「ひみつ」の景品になります（ほかの台には出ません）。ひみつの 3 体も含めて図鑑が全部そろうと、「ずかん コンプリート！」と知らせ、図鑑の枠が金色になります。

銀コインは最初に 10 枚持っています。コインの枚数の決まりは `js/config.js` の `CONFIG.coins` にまとめています。メニューの一番上に、持っている銀コインと金コインがいつも出ます。

難しさは全部の遊び方で共通です。

- かんたん：爪が大きく開き、つかむ力も強いので、景品の真ん中から少しずれていてもつかめる。アームは揺れない。爪のあるアーム（クラシック・おまかせ・2 ボタン・3 本爪）では、並んだ景品のあいだのような うまい位置に下ろすと、開いた爪の間にあるほかの景品もいっしょにつかめる（最大 3 個。爪の真ん中に近いほどつかみやすく、いっしょにつかんだ景品は運ぶ途中で落ちることもある。1 つ落ちたときは、残った景品を爪の真ん中でつかみ直す。ふつう・むずかしいは爪の開きが小さく、2 個だと爪からはみ出して見えるので 1 個だけ）。3 本爪では、かんたんのときだけ 3 個のうち 2 個をくっつけて置くので、その 2 個の真ん中が狙いどころになる（`CONFIG.threeClaw.easyPair`）。設定は `CONFIG.multiGrab` と `js/level.js` の `maxGrab` にある
- ふつう：ふつうの爪とつかむ力。アームは揺れない
- むずかしい：ふつうの爪とつかむ力。アームが揺れる。揺れが収まる前に下ろすと狙いがずれ、運ぶ途中で大きく揺れると景品を落としやすい

遊んでいる間は画面の上に「メニューへ」と「並べ直す」のボタンが出ます。Esc キーか「メニューへ」ボタンでメニューに戻り、R キーか「並べ直す」ボタンで景品を並べ直して最初から遊べます（ステップでは、並べ直すと新しいゲームになるので金コインを使います）。画面の上には、そのゲームで取った景品の数、残りの回数、持っているコインが出ます。

### 1. おまかせ（横から見た画面）

いちばんかんたんな遊び方です。アームが一定の速さで自動で左右に往復するので、ちょうどいいところでスペースキー（または Enter キー）を押すだけで遊べます。

- スペースキー（または Enter キー）：アームを下ろす

クラシックと比べて、景品は半分の 4 個です。

### 2. クラシック（横から見た画面）

- ← → キー：アームを左右に動かす
- スペースキー（または Enter キー）：アームを下ろす（つかんだら自動で取り出し口まで運ぶ）

### 3. 2ボタン（斜め前から見た画面）

本物のクレーンゲームと同じ操作です。① → ② の順に、それぞれ 1 回ずつしか押せません。

- ① ボタン（→ キーか 1 キー）：押している間アームが右へ動き、離すと止まる
- ② ボタン（↑ キーか 2 キー）：押している間アームが奥へ動き、離すとアームが下りる

床に映るアームの影を見ると、奥行きの位置を合わせやすくなります。

### 4. 3本爪（斜め前から見た画面）

3 本の爪で大きな景品を包むようにつかむモードです。景品は大きめで、最大 3 個だけ置かれます。

- ← → キー：左右に動かす
- ↑ キー：奥へ、↓ キー：手前へ動かす（何度でも、どの向きにも動かせる）
- スペースキー（または Enter キー）：アームを下ろす
- 1 回ごとに 15 秒の制限時間があり、過ぎると自動でアームが下ります

3 本爪は力が弱めなので、景品の真ん中をとらえないと落としやすくなります。

### 4-2. 2ボタン ガイド・3本爪 ガイド

2ボタンと 3本爪に、狙いやすくする「ねらいの光」を付けた台です。狙っている間は、爪の真下の床に赤い十字の印と点線が出て、爪と同じ奥行きの床に赤い光の帯が横いっぱいに出ます。帯がどの景品の列を通っているかを見ると、奥行きの位置を合わせやすくなります。それ以外の操作や決まりは、もとの台と同じです（`js/modes/floor.js` の `guide`）。

### 5. リング（横から見た画面）

取り出し口の右の台に、景品が 3 つ載っています。アームの先には丸いリングがぶら下がっていて、床には「？」の形のフックが立っています。フックと台の留め具はひもでつながっていて、リングをフックに引っかけて引き上げると台が傾き、載っている景品が全部取り出し口に流れ込みます。

- ← → キー：アームを左右に動かす
- スペースキー（または Enter キー）：アームを下ろす

リングはひもでぶら下がっているので、アームを動かしたり止めたりすると振り子のように揺れ、下ろすときも揺れながら下ります。アームはいつも、リングが床に届くところまで下ります。

フックの針金とリングの輪はすり抜けられず、上からかぶせてもリングはフックの肩に当たって（カツン）すべり落ちます。引っかけるには、下を向いたフックの先の下にリングをもぐり込ませ、引き上げるときに先を輪の中にくぐらせます。くぐったまま引き上げると、輪がフックの曲がった部分に引っかかってフックが持ち上がり、台が傾きます。フックの横から当たったり、先の正面から外れていたりすると、くぐらずに押し返されます。景品が取れると、新しい景品が置かれて続きます。そのたびにフックの位置と向き（先が右に垂れる右開き・左に垂れる左開き）、フックの大きさ（小・中・大）、リングの大きさ（小・中・大）がランダムに変わります。フックは、まっすぐな柱の上に円の 3/4 の輪が付いた「？」の形です。柱の高さはどの組み合わせでも同じで、小さいフックと大きいリングの組み合わせでも、フックの先の下にリングがくぐれる高さにしてあります。

難しさによって、揺れのおさまりやすさ、フックの先の向き（かんたんは真下を向いていてくぐらせやすく、むずかしいは内側へ巻き込んでいる）、引き上げる途中で外れる確率が変わります。

### 5-2. リング2だん（横から見た画面）

実機によくある 2 段の台です。上の段の左右に「？」のフックが 1 本ずつ立っていて、下の段の左右には景品を 2 つずつ載せた台があります。真ん中の下が取り出し口です。フックと、その真下の台の外側の端はひもでつながっていて、リングをフックに引っかけて引き上げると、台の外側が持ち上がって、載っている景品が真ん中の取り出し口へ流れ込みます。

- ← → キー：アームを左右に動かす（アームは真ん中の取り出し口の上で待つ）
- スペースキー（または Enter キー）：アームを下ろす（リングが上の段に届くところまで下りる）

リングの揺れ方や、フックの先にくぐらせる決まり、難しさごとの違いはリングと同じです。片方の台の景品が取れると、その台は空のまま残ります。フックも残るので、また引っかけて引き上げることはできますが、景品はもう落ちてきません。両方の台の景品が取れたら、両方の台に新しい景品が置かれ、フックの向き（左か右）がランダムに変わります。リングとフックの大きさはいつも「中」、フックの位置もいつも同じです。フックの「？」は、上から見ていろいろな向き（正面から、奥や手前へ回った向き）を向いていて、奥にある部分は暗く、手前にある部分は明るく見えます。リングも吊られているので、くるくる回ります（細い楕円に見えるときは、横を向いています）。リングがフックの先にかぶさる位置に来ても、リングの穴の向きがフックの先の向きにそろっていないと「カツン」とはじかれます。向きが合って引っかかりさえすれば、引き上げる途中で外れることはなく、景品が取れます。難しさで、どれだけ向きがそろえばよいか（`CONFIG.ring2.levels` の `align`）が変わります。上の段からは引き上げられる距離が短いので、ふつうのリングより少し引き上げただけで台が傾きます（`CONFIG.ring2.pullToOpen`）。設定は `CONFIG.ring2` にあり、リングとフックの大きさなどは `CONFIG.ring` を使います。

### 6. ショベル（斜め上から見た画面）

丸いドームの中で、景品を載せたテーブルが反時計回りに回っています。テーブルの左の柱から伸びた腕の先にショベルが吊られていて（ショベルは横から見た形）、テーブルの中心の少し左手前の上で止まって待っています。使うボタンは「下ろす」だけです。

- スペースキー（または Enter キー）：ショベルを下ろす

下ろすと、ショベルは「⊃」の形に動きます（持ち上げたまま右へ伸ばし、右へふくらみながら下りる）。下りる場所は毎回同じで、テーブルの中心の少し右手前です。そこから地面の砂をすくうように、時計の 4 時半から 7 時半あたりの線に沿って左へ引きながら景品をすくい、持ち上げて手前の真ん中の取り出し口まで運びます。取り出し口の上で傾けると、景品がすべり出て穴へ落ちていきます。ショベルは吊り棒とつながった蝶番を中心に傾きます。テーブルの真ん中には低い台があり、景品は台のまわりの輪の上（ふちまでは行かない）を回るので、短い通り道でも、どの景品も回ってくればショベルに届きます。ショベルの高さは、テーブルに落ちる影との離れ具合でわかります。テーブルが回って、景品がショベルの通り道に来るタイミングを狙って押します。ショベルのふちにかかっただけの景品は横へ押しのけられ、ふちの方に載った景品は持ち上げるときにこぼれやすくなります。

難しさによって、ショベルの幅と一度にすくえる数（かんたんは幅が広く 2 個まで、ふつう・むずかしいは 1 個）、こぼれやすさが変わります。むずかしいでは運ぶ途中でショベルが揺れます。

### 6-2. スウィート（斜め上から見た画面）

スウィートランド系の台です。ショベル（6.）と同じ見た目と仕組みに、プッシャーを加えています。奥の丸いドームの中で、景品を載せたテーブルが回っています。手前は 2 段のプッシャーです。上の段は前後に動く押し板の上で、下の段（床）は取り出し口に向かって広がる扇形です。どちらの段にも最初から景品が並んでいます。

- 「下ろす」（スペースキーか Enter キー）：ショベルを下ろす
- 「おとす」（↓ キー）：運んできた景品をプッシャーの床へ落とす。すくったあとは「下ろす」では落ちません（ボタンが 2 つあるので、まぎれないようにしています）

画面のボタンは、今押せるボタンだけがピンクになり、押せないボタンは暗くなります。アームが待っているあいだは「下ろす」、すくった景品をプッシャーの上まで運び終えたら「おとす」がピンクです。下ろしてから運び終えるまでは、どちらも押せません。ゲームが終わったあとは、「下ろす」で もういちど 遊べます。

押すと、ショベルが「ウィーン」と、1/4 円を描くように伸びながら斜めに下りて、毎回同じ場所で景品の山へ沈みます。少し止まってから引き上げます。沈んだ時点ではまだ何が入るか決まりません（止まっているあいだもテーブルは回り続けます）。引き上げるときは、ショベルらしく内側（軸の方）へ巻き込むように、引きながら口を上へ起こして持ち上げます。引きずっているあいだに口へ入った景品は、入るだけかき集めてすくうので、0 個のことも、何個も取れることもあります。すくった景品はプッシャーの床の上まで運ばれて止まるので、押し板の動きを見ながら、すきなタイミングで「おとす」を押します（6 秒押さないと自動で落とします）。落とした景品は、押し板の位置によって上の段か下の段に載ります。上の段の景品は、押し板が下がるときに奥の壁に止められ、ほかの景品に押されて、押し板の前のふちから下の段へ落ちます。下の段の景品は、押し板に押されてほかの景品を押し、手前のふちから取り出し口へ落ちるとゲットです。扇の左右のふちから落ちた景品は取れません。テーブルの景品が減ると、奥から足されます。文字がごちゃごちゃしないように、すくったときやこぼれたときに景品の上に文字は出さず、下の文字だけで知らせます。

難しさによって、ショベルの幅、一度にすくえる数（かんたん 4 個、ふつう・むずかしい 3 個まで）、こぼれやすさが変わります。むずかしいでは運ぶ途中でショベルが揺れます。設定は `CONFIG.sweet` にあります。

### 7. バンバン（横から見た画面）

台湾式のキャッチャーです。真ん中に取り出し口があり、その左右の高い床に景品がぎゅうぎゅうに 5 段ずつ積まれています（全部で 36 個。同じ景品がいくつも入っています）。操作はクラシックと同じです。

- ← → キー：アームを左右に動かす
- スペースキー（または Enter キー）：アームを下ろす

アームは 3 本爪で、ケーブルで吊られています。スピード感を出すため、ほかのモードより速く動きます。下ろすと、どの難しさでも大きく揺れながら下ります（左右に動かしたときにも揺れるのは、むずかしいだけです）。爪は景品をつかみますが、持ち上げる途中で投げてしまうことが多く、揺れる爪や本体に当たった景品は弾かれたり転がったりします。投げた景品は、アームが元の位置に戻るまで爪に当たらず、投げた瞬間に爪も大きく開きます。また、引き上げている間の爪と、つかんでいる景品は、ほかの景品を横に押しのけるだけで上には押し上げません。こうして、景品が爪の上に載ったまま運ばれないようにしています。床の内側（取り出し口の側）のふちから落ちた景品が獲得になります。ふちには低いでっぱりがあり、積んだ景品が勝手に崩れ落ちないように支えています。つかんだまま運べた景品は、取り出し口の上で離します。

難しさによって、つかめる確率、持ち上げる途中で投げる確率、投げる向き（取り出し口の側へ投げやすいか）、爪が景品を弾く強さ、ふちのでっぱりの高さ、景品どうしの滑りにくさ（積んだ山の崩れやすさ）が変わります。

### 7-2. おまかせバンバン（横から見た画面）

バンバンの台で、アームが一定の速さで自動で左右に往復します。おまかせと同じく、ちょうどいいところでスペースキー（または Enter キー）を押すだけで遊べます。景品の積み方や、揺れる爪がつかむ・投げる・弾く動きはバンバンと同じです。往復の速さは `CONFIG.banban.claw.autoSpeed` で決めています。

- スペースキー（または Enter キー）：アームを下ろす


### 8. ランダム

上のゲーム（ぬしの台を除く）のどれかが選ばれて始まります。気軽に遊べるように、下ろせる回数は 10 回ではなく 3 回です。難しさはメニューで選んでいるものになります。始まると「「クラシック」で あそぼう！」のように選ばれたゲームを知らせ、画面の下にも「ランダム：クラシック」と出します。操作は選ばれたゲームと同じです。

- 終わったあとは、2 つの遊び方から選べます。終了画面にも、この 2 つの案内を出します。
  - 「下ろす」など、ほかのゲームで「もういちど」遊ぶときと同じボタンを押すと、景品を並べ直さずに今の状態のまま、同じゲームを続けて 3 回遊べます。景品を全部取って終わったときは、続けられないので並べ直して最初から遊びます。
  - N キーか、画面の上に出る「次のランダム」ボタンを押すと、別のゲームを選び直します（前回と同じゲームは選ばれません）。
- R キーか「並べ直す」を押したときは、遊んでいる途中でも終わったあとでも、同じゲームのまま景品を並べ直して最初からやり直します。
- スマホなど幅のせまい画面では、画面の上のボタンが 3 つ並んでも 1 行に収まるように、ボタンのキーの案内（Esc・N・R）を省きます。

### 共通

- R キー（または「並べ直す」ボタン）：景品を並べ直して最初から（取った数と回数も最初に戻る）
- M キー：効果音のオン・オフ

画面の下のボタンでも操作できるので、スマホでも遊べます。

## ルール

- 1 ゲームで 10 回まで下ろせます（ランダムは 3 回）。回数を使い切るか、景品が全部なくなると終わりです。
- 1 ゲームで並ぶ景品の数は、クラシックと 2 ボタンが 8 個、おまかせが 4 個、3 本爪が大きめの 3 個、バンバンが 36 個です。
- 景品は くま・ねこ・ひよこ・うさぎ・ペンギン・おばけ・ボール・りんご・ぶた・さかな・いぬ・かえる・パンダ・ドーナツ の 14 種類と、たまに出るレア景品「きんのほし」があります（図鑑は全部で 15 種類）。
- 景品ごとに点数とつかみやすさが違います（ひよこ 10 点で一番つかみやすい、さかなはつるつるしていて 45 点、かえるもぬるっとしていて少しつかみにくい、きんのほし 100 点で一番つかみにくい）。点数は、売ったときの銀コインと、チャレンジでもらえる金コインの枚数のもとになります。
- ボール・りんご・ドーナツは丸いので、爪に押されたり落ちたりすると転がります。転がって取り出し口に入れば獲得になります。
- むずかしいでは、アームは動き出しや止まったときに揺れます。揺れが収まる前に下ろすと、狙った位置からずれます。運んでいる途中に大きく揺れると、景品を落としやすくなります。
- 景品の真ん中を狙うほどつかみやすく、途中で落としにくくなります。
- 獲得した景品は画面の下の「けいひん ずかん」に記録されます（全モードで共通）。図鑑・コイン・ステップの進み具合はブラウザに保存されるので、閉じても残ります。
- 図鑑で 2 こ以上持っている景品を押すと、1 こ売って銀コインになります（点数 ÷ 10、四捨五入、1 枚以上）。押したままにすると、続けて売れます（だんだん速くなり、1 こになると止まる）。図鑑の上の「ダブりを ぜんぶ うる」ボタンで、全部の景品を 1 こずつ残してまとめて売れます。1 こは残るので、図鑑は埋まったままです。図鑑の上には、今の銀コインも出ます。
- 図鑑の下の「コインと ずかんを リセット」ボタンで、確認のあとコインと図鑑を最初の状態に戻せます（ステップの進み具合は残ります）。
- 景品を並べるとき、落ちて積もったあとにどの景品にもアームが真上近くまで届くかを先に確かめ、届かない景品があれば落とす位置から選び直します。絶対に取れない並びで始まることはありません。

## フォルダ構成

```
index.html          画面の土台とメニュー。js/ のファイルをこの順番で読み込む
css/style.css       ページの見た目
js/config.js        画面サイズ・色・アーム（おまかせモード用の設定を含む）・景品・2 ボタンモードの床などの設定値
js/level.js         難しさ（かんたん・ふつう・むずかしい）ごとの、爪の開き・つかむ力・揺れ・一度につかめる数の設定
js/sprites.js       景品とアームのドット絵（1 文字が 1 ドット）と、景品ごとの点数・つかみやすさ
js/input.js         キーボードと画面のボタンの入力の管理
js/prize.js         クラシック・おまかせモードの景品の配置（アームが届くかのチェックを含む）と物理（重力・床・壁・景品どうしの衝突・転がり）
js/swing.js         アームの揺れ（全モード共通。かんたん・ふつうでは揺れを止める）
js/claw.js          クラシック・おまかせモードのアームの動き（おまかせでは自動で往復）と、景品をつかむ判定
js/effects.js       獲得したときの紙吹雪と文字の演出
js/sound.js         効果音（Web Audio で音を作るので、音声ファイルは不要）
js/collection.js    持ち物（図鑑・銀コイン・金コイン・ステップの進み具合）の保存と、図鑑で景品を売る処理
js/render.js        クラシックモードの画面と、共通の上下の表示・終了画面の描画
js/render_floor.js  2 ボタン・3 本爪モードの画面（斜め前から見た床・景品・2 本爪と 3 本爪のアーム・影・ガイドありの台のねらいの光と奥行きの帯）の描画
js/session.js       1 ゲーム分の進行（取った数・残り回数・コインの出入り・セリフ・終了判定）。全モード共通
js/modes/classic.js クラシックモードの進行
js/modes/auto.js    おまかせモードの進行（クラシックの仕組みに、自動の往復・大きく開く爪・強いつかむ力・4 個の景品を組み合わせる）
js/modes/floor.js   2 ボタン・3 本爪モードの共通部分（景品の配置とアームが届くかのチェック、アームの上げ下げ、つかむ判定、揺れ、景品の落下と転がり）
js/modes/button.js  2 ボタンモードの操作（① で右へ、② で奥へ）と設定（ガイドありの台も）
js/modes/three_claw.js 3 本爪モードの操作（十字キーで自由に移動、制限時間）と設定（ガイドありの台も）
js/modes/ring.js    リングモード（リングを下げたアーム、「？」のフック、傾く台と景品の流れ込み、描画）
js/modes/ring2.js   リング2だん（ring.js の仕組みを使い、上の段の左右のフックと、下の段の左右の台に広げたもの）
js/modes/shovel.js  ショベルモード（回るテーブルと景品、弧を描くショベルのアーム、すくう・こぼれる判定、描画。設定は cfg() で読むので、スウィートも同じ仕組みを使う）
js/modes/sweet.js   スウィート（ショベルの仕組みに、伸びながら斜めに沈み、止まってから内側へ巻き込んで引き上げる動き、「おとす」ボタン、2 段で扇形のプッシャーを加えたもの）
js/modes/banban.js  バンバンモード（高い床に積んだ景品と物理、揺れる 3 本爪のアーム、つかむ・投げる・弾く動き、描画）
js/modes/boss.js    ぬしの台（ステップの最後。アームを当てて ぬし の体力を減らす）
js/menu.js          メニューのゲームのボタンを、config.js の GAMES から作る（モードごとの並べ方）
js/main.js          起動処理、メニュー画面（ランダムでのゲームの選び方を含む）、メインループ
```

ES モジュールは使わず、`index.html` の `<script>` の順番で読み込んでいます。ファイルを直接開いたときもそのまま動かすためです。

`index.html` で読み込む css と js の後ろには `?v=20261115b` のような版の印を付けています。スマホのブラウザが古い css・js を覚えたまま新しい `index.html` と組み合わせて、表示が崩れたりボタンが効かなくなったりするのを防ぐためです。内容を変えて公開するときは、この印を全部同じ新しい値に書き換えてください。
